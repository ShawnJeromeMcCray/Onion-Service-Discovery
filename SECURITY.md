# Security policy

Onion Service Discovery is under initial development. No version is supported for production deployment.

Do not post credentials, private signing keys, search history or exploit details in public issues. A private vulnerability-reporting route must be configured and verified by the owner before release. No contact address or reporting capability is assumed here.

Application Service Identity, Node Identity, Tor identity and software-release keys remain separate. The application must never read Tor private keys. Technical verification does not establish content safety or human ownership.

External audit status: `EXTERNAL_AUDIT_NOT_PERFORMED`.
