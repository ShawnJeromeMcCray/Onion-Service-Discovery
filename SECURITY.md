# Security policy

Onion Service Discovery is a development preview. No version is supported for production deployment.

Do not post credentials, private signing keys, search history or exploit details in public issues. GitHub private vulnerability reporting is enabled (API readback verified on 2026-10-14). Use [Report a vulnerability](https://github.com/ShawnJeromeMcCray/Onion-Service-Discovery/security/advisories/new) for sensitive findings. Access requires a GitHub account; no response-time SLA or independent audit is implied. If the form is unavailable, do not substitute a public issue containing exploit details or secrets.

Application Service Identity, Node Identity, Tor identity and software-release keys remain separate. The application must never read Tor private keys. Technical verification does not establish content safety or human ownership.

External audit status: `EXTERNAL_AUDIT_NOT_PERFORMED`.
